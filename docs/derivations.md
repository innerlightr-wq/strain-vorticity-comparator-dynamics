## 0. Conventions

```
(grad u)_ij = d u_i / d x_j
S = (grad u + grad u^T)/2        W = (grad u - grad u^T)/2      (the papers' Omega)
omega_i = eps_ijk d_j u_k        W_ij = -(1/2) eps_ijk omega_k
Q_tot := ||grad u||_F^2          a := ||S||_F^2/Q_tot     b := ||W||_F^2/Q_tot
zeta := (||W||_F^2 - ||S||_F^2)/(||W||_F^2 + ||S||_F^2)
h := sqrt(ab)   L := (b-a)/2   D := 1/2 - h   R := 1/(4h^2)   eta_T := 2h
P := omega . S omega             A := P/(||S||_F |omega|^2)
```

Incompressibility (`div u = 0`) is used only where stated; it enters exclusively
through `tr S = 0`.

Two sign conventions exist in the source papers (the Archimedean note writes
`chi = b - a` in its plasma section, the companion repository writes `chi = a - b`).
Throughout this audit **`a` is the strain share and `b` the rotation share**, which
makes `L = +zeta/2`. Under the opposite labelling every statement below holds with
`L -> -L`; nothing else changes.

---

## 1. The kinematic decomposition (Phase 1) — **EXACT**

**Proposition 1.1.** For every real `3x3` matrix `grad u`:
`S:W = tr(SW) = 0`, hence `||grad u||_F^2 = ||S||_F^2 + ||W||_F^2`.

*Proof.* `tr(SW) = tr((SW)^T) = tr(W^T S^T) = -tr(WS) = -tr(SW)`, so `tr(SW) = 0`;
expanding `||S+W||_F^2` gives the norm identity. No physics, no incompressibility,
any dimension. ∎

**Proposition 1.2.** `|omega|^2 = 2 ||W||_F^2` and `W omega = 0` identically.

*Proof.* `W_ij W_ij = (1/4) eps_ijk eps_ijl omega_k omega_l = (1/2)|omega|^2`; and
`(W omega)_i = -(1/2) eps_ijk omega_j omega_k = 0` by antisymmetry. ∎

Proposition 1.2 also fixes the link between the partition and the physics with no
free factor: the rotation sector of the Pythagorean partition **is** the enstrophy
density,

```
e_omega := |omega|^2 / 2 = ||W||_F^2 ,      so      e_omega = b · ||grad u||_F^2 .
```

The allocation coordinate `b` is therefore the enstrophy share of the total
velocity-gradient energy exactly, not up to a convention.

## 2. The Thales embedding is an exact reparameterization — **EXACT**

With `a + b = 1`:

```
a = (1 - zeta)/2        b = (1 + zeta)/2
L = zeta/2                                     (bijective, dL/dzeta = 1/2)
h = (1/2) sqrt(1 - zeta^2)                     (even in zeta)
D = (1/2)(1 - sqrt(1 - zeta^2))                (even in zeta)
R = 1/(4h^2) = 1/(1 - zeta^2)                  (even)    eta_T = 2h = sqrt(1-zeta^2)
L^2 + h^2 = 1/4        L^2 = D(1 - D)
```

**Theorem 2.1 (information content).** Let `F` be the sigma-algebra generated by a
coordinate. Then

* `F(L) = F(a) = F(b) = F(zeta)` — the lateral coordinate is *exactly equivalent* to
  `zeta` (an affine rescaling, as `zeta` itself is an affine rescaling of the second
  invariant `Q_HWM = (||W||^2-||S||^2)/2`);
* `F(h) = F(D) = F(R) = F(eta_T) = F(|zeta|) ⊊ F(zeta)` — the altitude, the deficit,
  the response and the efficiency are **two-to-one** functions of `zeta`: they
  discard `sign(zeta)`, i.e. exactly the rotation-dominated / strain-dominated
  distinction that the `Q`-criterion, the Omega method and Okubo–Weiss all exist to
  make.

*Proof.* `L` is affine in `zeta` with nonzero slope. `h` is a strictly decreasing
function of `|zeta|` on `[0,1]`, hence a bijection of `|zeta|`, and `h(-zeta) = h(zeta)`;
`D`, `R`, `eta_T` are strictly monotone functions of `h`. ∎

**Corollary 2.2 (the first falsification).** No function of `(h, D, R, eta_T)` can
separate solid-body rotation from pure extensional strain: both have `h = 0`,
`D = 1/2`, `R = infinity`, while `zeta = +1` and `zeta = -1` respectively. Verified as
an explicit flow computation in `CANONICAL_FLOWS.md`.

**Remark 2.3 (the framework's own criterion, applied honestly).** Appendix B of the
Archimedean note states the rule: the Thales altitude carries independent
information *iff* the governing observable contains an amplitude-level cross term
between the channels. For the strain/rotation partition the amplitude cross term is
`S:W`, and Proposition 1.1 says it is **identically zero**. The very decomposition
that makes `a + b = 1` a Pythagorean partition is the decomposition that annihilates
the interference term. So the framework's own classification puts this partition in
the "additive" class, where by its own statement the altitude adds nothing. This is
consistency, not coincidence — and it is the cleanest available answer to the
question the brief asks in Phase 6.

## 3. The interaction term and the exact three-factor decomposition — **EXACT**

In the strain eigenframe (`S e_i = lambda_i e_i`, `sum lambda_i = 0` for incompressible
flow), `P = sum_i lambda_i omega_i^2`, and with `n = omega/|omega|`,
`P = |omega|^2 (n . S n) = |omega|^2 ||S||_F A`.

**Theorem 3.1 (sharp alignment bound; a specialization of Wolkowicz–Styan, restated
in RVP Thm 4.1).** For real symmetric traceless `S`, `max_i |lambda_i| <= sqrt(2/3) ||S||_F`,
with equality iff `S` has a repeated eigenvalue: `lambda = ||S||_F (2,-1,-1)/sqrt 6` (for the
`+` end) or `||S||_F (1,1,-2)/sqrt 6` (for the `-` end). Hence
`|A| <= sqrt(2/3) = 0.816496581...`, with equality iff additionally `omega` is parallel to
the distinct eigenvector. *(Re-derived independently here by Lagrange multipliers;
claimed as neither new nor ours.)*

**Theorem 3.2 (exact scale × allocation × alignment factorization).**

```
P = ||grad u||_F^3 · g(zeta) · A ,      g(zeta) = (1 + zeta) sqrt((1 - zeta)/2) = 2 b sqrt(a)
```

*Proof.* `||S||_F = sqrt(a Q_tot)`, `|omega|^2 = 2 b Q_tot` (Prop. 1.2), so
`P = |omega|^2 ||S||_F A = 2 b sqrt(a) Q_tot^{3/2} A`; substitute `a,b` in terms of `zeta`. ∎

This is precisely the decomposition the brief asks for in Phase 3 —
`production = scale × allocation factor × alignment` — and it is exact, not schematic.

**Corollary 3.3 (the allocation factor is not the Thales altitude).**
`g(zeta) = 2 h sqrt(b) = h sqrt(2(1 + zeta))`. The altitude appears in `g` only up to a
factor that itself depends on the allocation; `g/h = sqrt(2(1+zeta))` is non-constant, so
no rescaling of `h` equals `g`. The correct allocation monomial is `a^{1/2} b^1` — a
*mixed-power, asymmetric* combination, distinct both from the symmetric geometric
mean `h = (ab)^{1/2}` (the Archimedean note's "amplitude" case) and from a linear
function of `a` (its "additive" case). **The partition enters enstrophy production
through a third functional form that the two-case classification of Appendix B does
not contain.** This is the one place where the Thales construction is genuinely
*wrong* rather than merely redundant: an analyst who used `h` as the coupling
coordinate would be using `(ab)^{1/2}` where the equations contain `a^{1/2} b`.

**Theorem 3.4 (sharp global pointwise bound).** For every incompressible velocity
gradient,

```
omega . S omega  <=  (4 sqrt 2 / 9) ||grad u||_F^3 ,        4 sqrt 2 / 9 = 0.628539361...
```

with equality iff (i) `||W||_F^2 = 2 ||S||_F^2`, i.e. `zeta = 1/3` (equivalently
`|omega|^2 = 4||S||_F^2`, `a = 1/3`, `b = 2/3`); (ii) `S` is axisymmetric with
`lambda = ||S||_F (2,-1,-1)/sqrt 6`; (iii) `omega` is parallel to the eigenvector of the
positive eigenvalue.

*Proof.* By Thm 3.2 and Thm 3.1, `P/||grad u||_F^3 = g(zeta) A <= sqrt(2/3) g(zeta)`.
`g'(zeta) = (1 - 3 zeta) / (2 sqrt(2(1 - zeta)))` vanishes only at `zeta = 1/3`, where
`g = 4/(3 sqrt 3)`; `g` is positive and vanishes at both endpoints, so this is the
maximum. Then `sqrt(2/3) · 4/(3 sqrt 3) = 4 sqrt 2/9`. The three equality conditions
are the equality conditions of the two steps, which are simultaneously satisfiable
because `A` is invariant under scaling of `S` and of `omega` while `zeta` is invariant
under rotations — so the constraints are independent. An explicit attaining state
is `S = diag(2,-1,-1)/sqrt 6`, `omega = (2,0,0)`, giving `||grad u||_F^2 = 3`,
`P = 4 sqrt 6/3`, ratio `4 sqrt 2/9`. ∎

*Status note.* The `sqrt(2/3)` factor is classical. The additional step — optimizing
over the allocation to express the bound in terms of `||grad u||_F` alone — is
elementary and we make **no priority claim**; it is very likely known in the
velocity-gradient-invariant literature. It matters here because it is the first
place where the allocation coordinate `zeta` acquires a *derived* distinguished value,
and that value is `1/3`, not `0`.

**Theorem 3.5 (relative-growth allocation law).** For the enstrophy density
`e = |omega|^2/2`, the production contribution to the normalized material growth rate
is

```
P / (||grad u||_F · e)  =  A sqrt(2 (1 - zeta)) ,
```

strictly decreasing in `zeta`: maximal as `zeta -> -1` (strain-dominated), not at
`zeta = 1/3`, and not at the apex.

**Corollary 3.6 (normalization is not innocent).** Two exact and equally natural
normalizations give two different "optimal allocations": absolute production at
fixed total gradient peaks at `zeta = +1/3`; relative (per-enstrophy) growth peaks at
`zeta -> -1`. **Neither is the Thales apex `zeta = 0`.** Any claim that a partition
landmark is dynamically optimal must therefore name its normalization first.

**Theorem 3.7 (production envelope).** At fixed `zeta`, the attainable set of
`P/||grad u||_F^3` is exactly the closed interval
`[-sqrt(2/3) g(zeta), +sqrt(2/3) g(zeta)]`, and every interior value is attained.
So `zeta` bounds the magnitude of normalized production and determines nothing
inside the bound — in particular nothing about its sign.

**Corollary 3.8 (two bounded efficiencies).** Dividing Theorem 3.2 by the global
maximum of Theorem 3.4,

```
P / [ (4 sqrt 2 / 9) ||grad u||_F^3 ]  =  E_alloc(zeta) · E_align(A) ,

E_alloc(zeta) = g(zeta)/g(1/3) = (3 sqrt 3/4)(1+zeta) sqrt((1-zeta)/2)  in [0, 1] ,
E_align(A)    = A / sqrt(2/3)                                          in [-1, 1] ,
```

each factor dimensionless and bounded by 1, `E_alloc = 1` exactly at `zeta = 1/3` and
`E_align = 1` exactly at the axisymmetric aligned state. This is the form in which the
"allocation × alignment" picture is actually usable: two efficiencies and a scale.
(It is a rescaling of Thm 3.2, not new content.)

**Remark 3.9 (a shared degeneracy).** `A` is undefined exactly at `zeta = +1`
(`||S||_F = 0`) and `zeta = -1` (`|omega| = 0`) — which are precisely the two points
where the Thales altitude `h` vanishes. The two coordinate systems degenerate at the
same two states, for opposite reasons: `h = 0` because one sector is empty, `A`
undefined because the empty sector is the one alignment needs.

## 4. Non-identifiability of `P` from magnitudes (Phase 2) — **EXACT**

**Theorem 4.1 (functional independence; the image is a product set).** The map
`(S, omega) -> (zeta, A)` is onto `(-1,1) x [-sqrt(2/3), sqrt(2/3)]`. Explicitly, for any
target `(zeta_0, A_0)` in that rectangle, take `lambda = (2,-1,-1)/sqrt 6` if `A_0 >= 0` and
`(1,1,-2)/sqrt 6` otherwise, put `omega` in the plane of the extreme eigenvectors with
`cos^2` weight `c = (A_0 - lambda_min)/(lambda_max - lambda_min)` on the extreme one, and set
`||W||_F^2 = ||S||_F^2 (1+zeta_0)/(1-zeta_0)`. Then `zeta = zeta_0` and `A = A_0` exactly.
(Checked on a 41×41 grid to `3.6e-16`.)

**Corollary 4.2.** There is **no** conditional bound, forbidden region, or symmetry
relation linking `zeta` to `A`: the joint admissible set is a rectangle. `zeta` therefore
carries *exactly zero* information about alignment, and hence exactly zero
information about the sign of `P`. The non-identifiability is complete, not partial.

**Exact witnesses.** With `S = diag(1,0,-1)` (so `||S||_F^2 = 2`) and `|omega|^2 = 2`:

| `omega` | `zeta` | `h` | `L` | `A` | `P` |
|---|---|---|---|---|---|
| `(sqrt2,0,0)` | `-1/3` | `sqrt2/3` | `-1/6` | `+1/sqrt2` | `+2` |
| `(0,sqrt2,0)` | `-1/3` | `sqrt2/3` | `-1/6` | `0` | `0` |
| `(0,0,sqrt2)` | `-1/3` | `sqrt2/3` | `-1/6` | `-1/sqrt2` | `-2` |

Identical `||S||_F`, `||W||_F`, `|omega|`, `zeta`, `a`, `b`, `h`, `L`, `D`, `R`; all three
signs of `P`. The same construction at `|omega|^2 = 4` puts three states at the
**Thales apex** `zeta = 0, h = 1/2, D = 0` with `P = +4, 0, -4`: maximal Thales
"coherence" is compatible with stretching, nothing, or compression.

**What the projection destroys, counted exactly.** `(S, omega)` has `5 + 3 = 8`
degrees of freedom; modulo the `SO(3)` that acts on both, `5` invariants remain, and
a convenient complete set is

```
||S||_F ,  s (strain state) ,  |omega| ,  cos^2(omega, e_1) ,  cos^2(omega, e_2)
```

with `s = -3 sqrt 6 det S / ||S||_F^3` the Lund–Rogers parameter. Then:

* `zeta` is a function of `(||S||_F, |omega|)` only — **2 of the 5**, and only their ratio;
* `A` is a function of `(s, cos^2_1, cos^2_2)` only — it collapses **3 into 1**;
* `(||grad u||_F, zeta, A)` is exactly **sufficient for `P`** (Thm 3.2) and discards the
  remaining **2** invariants.

**Theorem 4.3 (sufficiency and necessity for instantaneous production).** `P` is a
function of `(||grad u||_F, zeta, A)` and of no strict sub-triple: scaling `S` and
`omega` together changes `P` at fixed `(zeta, A)` (scale necessary); changing the
`||S||:||W||` split changes `P` at fixed `(scale, A)` (allocation necessary); rotating
`omega` in the strain eigenframe changes `P` — including its sign — at fixed
`(scale, zeta)` (alignment necessary). All three are demonstrated in
`experiments/synthetic_fields/ensembles.py` §9.1–9.4.

## 5. An exact null for mean production — **EXACT**

If the orientation of `omega` is isotropic and independent of `S`, then
`E[cos^2 theta_i] = 1/3` for each eigen-direction, so

```
E[A | S, |omega|] = (lambda_1 + lambda_2 + lambda_3) / (3 ||S||_F) = 0
```

for any traceless `S`, and hence `E[P] = 0`. **A nonzero mean enstrophy production is
therefore entirely an alignment-correlation effect.** `zeta` is invariant under the
rotations that generate this null, so it contains no information about the effect
that makes `<P> > 0` in real turbulence. (Confirmed numerically: a Gaussian
solenoidal field has `<P/||grad u||^3> = +4.6e-05 ± ...`, i.e. zero.)

## 6. What none of this implies

1. **No threshold.** Theorem 3.7 is a bound, not a threshold: nothing here
   separates dynamical regimes by a critical value of `zeta`, `A`, or any function of
   them. This agrees with RVP §6.3 ("no corridor found") and we reproduce it rather
   than overturn it.
2. **Sufficiency is instantaneous only.** `(scale, zeta, A)` determines `P` exactly but
   not the *evolution* of enstrophy: two states identical in
   `(||grad u||_F, zeta, h, L, D, A, P)` but with opposite strain state
   (`s = -1` vs `s = +1`) diverge under restricted-Euler dynamics
   (amplification differs by `0.0285` nats over `t = 0.8`; `experiments/synthetic_fields/restricted_euler.py` T3).
   The discarded 2 invariants are dynamically live even though they are
   instantaneously irrelevant to `P`.
3. **A near-coincidence that is not an identity.** The production-optimal allocation
   is `b = 2/3` exactly. The Archimedean/constraint-geometry framework's cubic
   landmark is the root of `b^3 + b - 1 = 0`, `b_* = 0.6823278038...`. These differ:
   substituting `b = 2/3` into the cubic leaves exactly `-1/27`, a relative gap of
   `2.30%`. **They are different numbers and must not be conflated.** We flag this
   because `0.667` and `0.682` are close enough to invite exactly the retrospective
   fit the brief forbids.
4. **`A` is a compression, not a replacement.** As RVP Remark 4.4 already says, `A`
   collapses three alignment cosines into one number and discards *which*
   eigenvector the vorticity favours — the question that has been the interesting
   one since Ashurst et al. (1987). Everything proved above about `A`'s sufficiency
   is sufficiency *for `P`*, and `P` is not the whole of the dynamics.
