## Determinism

Every random generator is an explicitly seeded `numpy.random.default_rng`. Seeds are
listed in `EXPERIMENT.md`. Reruns reproduce all reported digits on the same numpy
version; the FFT-based Gaussian ensemble and the DNS depend on numpy's FFT, so a
different BLAS/FFT build may move the last one or two digits of aggregate statistics
without changing any conclusion.

## Files written

Only inside the working directory: `.venv/` (~440 MB, the installed dependencies),
`results/*.json`, `results/*.npz`, `results/dns_run.log`, `figures/*.png`. No existing
repository was touched during the audit — verified after each run by checking
modification times across the user's repositories.

*Provenance note:* the audit was performed in a standalone working directory outside
any repository; the scripts, documents, results and figures were copied into this
repository afterwards, with file paths updated to the layout described in
[`../README.md`](../README.md). The archival working copy was left unmodified.

Figures are rendered light-surface only (static PNGs for a written report); the
palette, its validated categorical ordering and the diverging/ordinal ramps are
documented at the top of `src/figures_allocation.py`.

## Data provenance

No external data. Every number is generated by the scripts here from closed-form
definitions, symbolic algebra, seeded pseudo-random ensembles, or the DNS solver in
this directory. The two source manuscripts were read from
`~/Downloads/Archimedean_Compensationv1 (1).pdf` and `~/Downloads/RVP.pdf` and were
**not modified**; their text is quoted only in the documentation here.
